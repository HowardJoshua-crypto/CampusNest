# Roadmap

## Phase 1: Foundation
- Finalize concept note and product requirements
- Define user roles and permissions
- Design database schema
- Set up repo and documentation

## Phase 2: MVP build
- Student auth and onboarding
- Landlord listing submission
- Listing moderation and verification
- Search and filter
- Review and reporting flows
- Admin dashboard basics

## Phase 3: Pilot
- Onboard one university
- Verify listings around one campus
- Collect student feedback
- Measure trust and usability

## Phase 4: Expansion
- Add more campuses
- Add smarter area insights
- Add booking and payment support
- Add automated reporting and policy exports
