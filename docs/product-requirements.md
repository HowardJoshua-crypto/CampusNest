# Product Requirements

## Product goal
Build a trusted university-linked accommodation platform that improves housing access for students and provides residential intelligence for university decision-making.

## User roles
1. Student
2. Landlord
3. University administrator
4. Welfare officer
5. Super admin

## Functional requirements
### Student
- Register and sign in
- Search listings by area, price, distance, and amenities
- View verified housing details
- Save favorite listings
- Submit ratings and reviews
- Report housing or safety issues

### Landlord
- Register and verify identity
- Create and manage property listings
- Upload images and room details
- Respond to inquiries

### University admin
- Review approved / flagged areas
- Access area-level dashboards and reports
- View trends by zone, rent range, and complaint category
- Export policy support reports

### Super admin
- Manage platform roles
- Moderate reports and high-risk listings
- Manage university configuration

## Non-functional requirements
- Secure authentication
- Role-based access control
- Privacy-aware residential analytics
- Responsive web experience
- Scalable storage for images
- Audit trails for moderation actions

## MVP success indicators
- Number of verified listings
- Number of student sign-ups
- Search-to-contact conversion rate
- Number of issue reports resolved
- Admin usage of area insights
