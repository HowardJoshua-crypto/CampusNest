# Web App

This workspace is intended for the university-linked web portal.

Using HTML and CSS to visualize the platform’s user interface, to iterate on user experience details, and gather early feedback before investing in backend development. Build static pages.


## Suggested initialization
```bash
npm create vite@latest apps/web -- --template react-ts
```

## Core web modules
- Landing Page / Home Screen showcasing the platform’s purpose and user types
- Search and Listing Pages with filters, property cards, and comparison layouts
- User Profile Pages for students and landlords
- Messaging Interface mockup for communication
- Review and Rating Sections
- Admin Dashboard Layout with charts and key metrics (using placeholders)
